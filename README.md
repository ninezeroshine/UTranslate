# UTranslate

Переводчик для Windows, живущий в трее: выделил текст в любой программе, нажал `Ctrl+Alt+T` — перевод в капсуле у курсора. Бесплатные движки без ключей, замена выделенного текста переводом, история, избранное.

- Код и инструкция по запуску: [app/README.md](app/README.md)
- Дизайн-исходники (направление «Капсула»): [design/](design/)

Стек: Tauri 2 (Rust) + React 19 + TypeScript + Tailwind CSS v4 + Motion.
