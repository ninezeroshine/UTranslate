## Что это

Выделил текст в приложении с поддержкой `Ctrl+C`/`Ctrl+V`, нажал `Ctrl+Alt+T` — рядом с курсором всплывает капсула с переводом. Второй хоткей заменяет выделенное переводом прямо в поле ввода. Третий обводит область экрана: текст с картинки, видео или из окна без выделения распознаётся локально и переводится в той же капсуле. Движки по умолчанию бесплатные, без ключей и регистрации. Данные не покидают компьютер, кроме самого текста, который уходит в выбранный движок перевода.

## Возможности

- **Перевод области экрана** — `Ctrl+Alt+S`: тихий нативный оверлей, русский и английский распознаются локально (PP-OCRv5 в комплекте), карточка встаёт под обведённой областью. Снимок не уходит в сеть и не попадает в буфер обмена.
- **Попап у курсора в приложениях с поддержкой `Ctrl+C`/`Ctrl+V`** — браузер, мессенджер, редактор, терминал: захват выделения через эмуляцию клавиш, как в QTranslate.
- **Замена текста на месте** — второй хоткей переводит и вставляет результат в то же поле, если исходное окно и выделение всё ещё те же; при изменении контекста операция отменяется. Буфер обмена возвращается как был, после вставки всплывает тост «Заменено: …».
- **Три движка без ключей** — Google → Bing → MyMemory, при отказе одного автоматический переход на следующий с бейджем причины.
- **Правка и выбор движка в карточке** — карандаш в подвале открывает редактор перевода, бейдж движка переключает Google, Bing или MyMemory для этого перевода, «Оригинал» раскрывает исходник, а при переводе с экрана даёт поправить распознанный текст.
- **Автоопределение языка и swap** — если выделенный текст уже на основном языке, перевод идёт на запасной, вручную переключать не нужно.
- **Словарный режим** — для одного-двух слов вместо перевода-фразы показываются варианты значений по частям речи.
- **История с поиском и избранное** — каждый перевод сохраняется в локальную SQLite, поиск по подстроке, избранное экспортируется в CSV.
- **Закрепление попапа** — капсула остаётся на экране до явного закрытия и обновляется по следующему хоткею.
- **Тема системная, тёмная или светлая** — переключается в настройках, попап и окно следуют выбору без перезапуска.
- **Автозапуск с Windows** и работа из трея без окна на экране.
- **Автообновление** — подписанный установщик, проверка через 15 секунд после старта и каждые 6 часов, пункт «Обновить до X» в трее.
- **Без телеметрии** — сетевые обращения только к выбранному движку перевода и к GitHub Releases за обновлением.

## Установка

1. Скачайте установщик со страницы [Releases](https://github.com/ninezeroshine/UTranslate/releases/latest) и запустите.
2. Windows SmartScreen предупредит про неизвестного издателя — установщик подписан ключом обновлений, но не сертификатом издателя. Нажмите «Подробнее» → «Выполнить в любом случае».
3. После установки UTranslate работает из трея, окно на экране не открывается.

Хоткеи по умолчанию:

| Действие | Сочетание |
|---|---|
| Перевести выделенное в попап | `Ctrl+Alt+T` |
| Перевести область экрана | `Ctrl+Alt+S` |
| Заменить выделенное переводом | `Ctrl+Alt+R` |
| Открыть окно | `Ctrl+Alt+W` |

Меняются в Настройках → Хоткеи. Сочетание, занятое другой программой, помечается сразу при попытке назначить.

Обновляется само: проверка через 15 секунд после запуска и раз в 6 часов, при находке — пункт «Обновить до X.Y.Z» в меню трея и в разделе «О программе».

## Как пользоваться

**Перевести выделенное.** Выделите текст в приложении с поддержкой `Ctrl+C`/`Ctrl+V` → `Ctrl+Alt+T` → капсула у курсора разворачивается в карточку с переводом. `Esc`, клик вне окна или потеря фокуса закрывают попап.

В карточке нажмите **«Заменить»**, чтобы подставить уже показанный перевод вместо исходного выделения без повторного перевода и хоткея. Замена выполняется только пока исходное окно, поле и выделение доступны; иначе операция отменяется.

Значок карандаша в подвале карточки открывает редактор перевода. **«Готово»** сохраняет изменённый текст в истории, **«Отменить»** или `Esc` отменяют правки; `Enter` вставляет новую строку, `Ctrl+Enter` завершает редактирование. Копирование, озвучивание и замена используют текущий черновик. Бейдж движка в шапке открывает выбор Google, Bing, MyMemory или **«Автоматически»** для текущего текста; выбор действует только для этого перевода. **«Оригинал»** справа в подвале раскрывает исходный текст.

**Заменить текст в поле.** Выделите текст → `Ctrl+Alt+R` → на месте выделения оказывается перевод, если окно и выделение не менялись во время запроса. При изменении контекста вставка отменяется. Буфер обмена после операции возвращается как был; у курсора на 2 секунды всплывает капсула «Заменено: …».

**Открыть окно и перевести вручную.** `Ctrl+Alt+W` открывает главное окно с вкладками Перевод, История, Избранное, Настройки; если было выделение, оно подставляется в поле источника.

**Перевести текст с экрана.** Нажмите `Ctrl+Alt+S` или **«С экрана»** — экран замирает и мягко темнеет. Обведите текст на любом мониторе, хоть через границу экранов; отпустили кнопку — под областью появляется капсула «Распознаём…», затем обычная карточка. Ошибки распознавания правятся в блоке **«Оригинал»**, **«Выделить заново»** открывает оверлей ещё раз, `Esc` и правая кнопка отменяют. OCR понимает русский и английский; [как устроено и что ограничено](docs/screen-translation.md).

Для одного-двух слов попап переходит в словарный режим и вместо перевода фразы показывает варианты значений. Значок булавки в шапке попапа закрепляет его на экране — он остаётся открытым и обновляется по следующему хоткею, пока его не закрыть явно.

## Как устроено

```mermaid
sequenceDiagram
    participant U as Пользователь
    participant OS as Windows
    participant Core as Rust-ядро
    participant Eng as Движки перевода
    participant UI as Попап (React)

    U->>OS: выделяет текст, жмёт Ctrl+Alt+T
    OS->>Core: RegisterHotKey
    Core->>OS: SendInput Ctrl+C
    OS-->>Core: буфер обмена сменился
    Core->>Core: вернуть буфер обмена, whatlang: догадка о языке
    Core->>UI: событие popup:show (текст, язык, позиция у курсора)
    Core->>Eng: перевод (Google → Bing → MyMemory)
    Eng-->>Core: перевод или ошибка → следующий движок
    Core->>UI: popup:result / popup:error
    UI-->>U: карточка с переводом
```

Перевод с экрана идёт тем же путём, только источник текста — локальное распознавание:

```mermaid
sequenceDiagram
    participant U as Пользователь
    participant Sel as Оверлей (Win32, GDI+)
    participant OCR as OCR (PP-OCRv5, ONNX Runtime)
    participant Eng as Движки перевода
    participant UI as Попап (React)

    U->>Sel: Ctrl+Alt+S
    Sel->>Sel: снимок всех мониторов, затемнение за 120 мс
    U->>Sel: обводит область, отпускает кнопку
    Sel-->>UI: popup:show «Распознаём…» под выделением
    Sel->>OCR: RGBA-кроп, только в памяти
    OCR-->>UI: popup:recognized (текст, язык)
    OCR->>Eng: только распознанный текст
    Eng-->>UI: popup:result
```

| Файл | Что делает |
|---|---|
| `app/src-tauri/src/lib.rs` | команды, хоткеи, трей, апдейтер, поток «захват → перевод → попап» |
| `app/src-tauri/src/capture.rs` | эмуляция `Ctrl+C` / `Ctrl+V` с возвратом буфера обмена |
| `app/src-tauri/src/screen_capture.rs` | нативный оверлей выбора области: снимок мониторов, затемнение, рамка, анимации прозрачности |
| `app/src-tauri/src/ocr.rs` | локальное распознавание PP-OCRv5 через ONNX Runtime: плитки, порядок чтения, выгрузка по простою |
| `app/src-tauri/src/screen_translation.rs` | сценарий «оверлей → OCR → перевод → попап» и lifecycle окон |
| `app/src-tauri/src/engines.rs` | Google, Bing, MyMemory, цепочка с fallback и кэшем |
| `app/src-tauri/src/db.rs` | история и избранное, SQLite |
| `app/src-tauri/src/popup.rs` | окно попапа: позиция у курсора или под выделением, размер под содержимое |
| `app/src/popup/` | капсула: `Popup.tsx` с состояниями и морфингом пилюля → карточка, шапка, подвал, меню движков, редактор |
| `app/src/main/Main.tsx` | главное окно: Перевод, История, Избранное, Настройки |
| `app/src/ui/` | общие компоненты интерфейса |

Стек: Tauri 2 (Rust) + React 19 + TypeScript + Tailwind CSS v4 + Motion.

Приватность: текст уходит только выбранному движку перевода, больше никуда. Снимки для OCR обрабатываются только в памяти на компьютере, модели и ONNX Runtime лежат в комплекте с приложением, ничего не докачивается. Все данные — локально, в `%APPDATA%\com.utranslate.app\` (`settings.json` и `utranslate.db`), телеметрии и аналитики нет.

## Сборка из исходников

Требуется: Windows 10/11, [Node 22](https://nodejs.org), pnpm 10, Rust stable (MSVC), WebView2 Runtime (в Windows 11 уже установлен).

```bash
cd app
pnpm install
pnpm tauri dev          # dev-режим, Vite поднимается на 127.0.0.1:1420
```

Vite слушает только IPv4 (`127.0.0.1`) — на `localhost` Tauri CLI может ждать порт до 180 секунд.

Перед первым запуском `pnpm ocr:prepare` сам скачает модели OCR и ONNX Runtime (около 90 МБ, один раз); подробности в [`tools/ocr/README.md`](tools/ocr/README.md).

```bash
cd app/src-tauri && cargo test              # юнит-тесты ядра
cd app && pnpm exec tsc --noEmit            # проверка типов
cd app && pnpm test:frontend                # тесты очередности запросов и избранного
cd app && pnpm test:popup                   # Playwright-тесты геометрии попапа
cd app && pnpm build                         # production frontend build
cd app && pnpm tauri build                  # NSIS-установщик
```

Релиз:

```bash
pnpm release 0.3.0
```

Скрипт проставляет версию в `package.json`, `src-tauri/tauri.conf.json` и `Cargo.toml`, коммитит, ставит тег и пушит. Дальше GitHub Actions (`.github/workflows/release.yml`) собирает установщик через `tauri-action`, подписывает его ключом из секрета `TAURI_SIGNING_PRIVATE_KEY` и публикует релиз с `latest.json` для автообновления.
