# UTranslate

Переводчик для Windows, живущий в трее. Выделил текст в любой программе, нажал хоткей — через полсекунды перевод в капсуле у курсора. Бесплатные движки без ключей: Google → Bing → MyMemory.

Документы проекта лежат уровнем выше: [PRD.md](../PRD.md), дизайн в `../design/`. Правила анимаций и геометрии попапа — [docs/motion.md](docs/motion.md).

## Хоткеи по умолчанию

| Действие | Сочетание |
|---|---|
| Перевести выделенное в попап | `Ctrl+Alt+T` |
| Заменить выделенное переводом | `Ctrl+Alt+R` |
| Открыть окно | `Ctrl+Alt+W` |

Все меняются в настройках. Занятое другой программой сочетание помечается при сохранении.

## Стек

Tauri 2 (Rust-ядро: хоткеи, захват через эмуляцию Ctrl+C, движки, SQLite) + React 19, TypeScript, Tailwind CSS v4, HeroUI v3, Motion.

## Запуск

Нужны Rust (MSVC), Node 22, pnpm, WebView2 (в Windows 11 уже есть).

```bash
pnpm install
pnpm tauri dev
```

Сборка установщика:

```bash
pnpm tauri build
```

Юнит-тесты ядра:

```bash
cd src-tauri && cargo test
```

## Где что лежит

```
src-tauri/src/
  lib.rs       команды, хоткеи, трей, поток «захват → перевод → попап»
  capture.rs   эмуляция Ctrl+C / Ctrl+V с возвратом буфера обмена
  engines.rs   Google, Bing, MyMemory, цепочка с fallback и кэшем
  db.rs        история и избранное (SQLite)
  settings.rs  настройки (JSON)
  popup.rs     показ попапа у курсора
src/
  popup/Popup.tsx   капсула: пилюля → карточка
  main/Main.tsx     окно: Перевод, История, Избранное, Настройки
  lib/api.ts        обёртки над командами Tauri
```

Данные: `%APPDATA%\com.utranslate.app\` — `settings.json` и `utranslate.db`.

## Известные ограничения

- Буфер обмена возвращается только для текста; картинка или файлы в буфере теряются.
- Журнал буфера обмена Windows (`Win+V`) записывает промежуточную копию.
- Настоящего размытия рабочего стола под попапом нет: WebView2 не размывает то, что под окном.
