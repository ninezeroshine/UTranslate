# Отвергнутые варианты иконки

Смотрели рендеры 16 / 20 / 24 / 32 / 48 px на тёмной (#202020) и светлой (#f3f3f3)
панели рядом с заглушками Telegram, Discord и Steam.

- `1-pill-thin.svg` — та же капсула со стрелкой, но пилюля ниже (608 против 664) и стрелка
  тоньше. На 16 px мельче соседей и стрелка теряет вес. Принятая `../icon.svg` — её версия
  с увеличенной пилюлей.
- `2-halves.svg` — две половины, лаванда и бирюза, белый шов по диагонали. На 16 px шов
  исчезает, остаётся двухцветное пятно без смысла; в ряду читается как индикатор батареи.
- `3-diagonal.svg` — капсула под −30° со стрелкой вдоль оси. Диагональ на 16 px даёт
  сплошное размытие: ни силуэта, ни стрелки.
